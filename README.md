# To-Do List

It is a simple to-do list that allows the user to add items to the list and edit it.

## 🎯 How It Works
- First, the list is entered.
-The system then asks if the user wishes to make any modifications;
-if the user selects "Yes," the editing options are displayed, and upon making a selection, the new list is printed.

## ✨ Features
- Simple and quick To-Do List
- Simple Modifications
- Clean and easy-to-use input

## 🛠️ Built With
- Python
